# AI 修改行为规范

> **动手前还有一道闸**：任何功能开发 / 缺陷修复 / 移植，都必须先交 13 栏《开发报告》——见 `10-dev-template.md`。
> 本文件是**第二道闸**，规定动手之后怎么交付。

## 五条元规则（违反任何一条，本次改动作废）

### 1. 最小修改原则

只改解决问题**必需**的那几行。

- ❌ 不顺手改变量名让它"更规范"
- ❌ 不顺手格式化旁边的代码
- ❌ 不顺手"优化"看着不顺眼的写法
- ❌ 一个改动里塞进两件事

理由：每多改一处，爆炸半径就大一分；而且真正的改动会被淹没，出问题时没法二分定位。

### 2. 禁止未经确认的大规模重构

**判断标准**：如果一个改动**不改变外部行为**，只是让代码"更好看"——它就是重构，**不做**。

明确不重构的地方：

| 地方 | 为什么 |
|---|---|
| `tasks/GameUi/` 页面导航（143 文件 + Dijkstra + 边惩罚） | 全项目最复杂、最依赖实测数据 |
| `config_model.py` 的自动写盘 | 看着不优雅，但 GUI 实时改参依赖它 |
| 图像/OCR 的 RPC 调用链 | 没有本地兜底是刻意设计 |
| `script.py` 的异常处理总闸 | 全局唯一安全网 |
| `module/atom/scatter.py` | 半移植状态，配套改造拿不到 |

重构必须有**独立的重构需求** + **人工批准**。

### 3. 禁止猜测源码

说"这个文件是干什么的""这个函数会返回什么"之前，**必须 Read / Grep 核实**。

不确定的一律标"**待确认**"，不许用"应该是""大概是"糊过去。

**本项目已两次因猜测出错**：
- `instance_guard`：以为是"hurry2 没有"，实为"合过又主动删了"
- `_exit_matcher`：以为是复制粘贴，实为钩子模式（差点被"优化"掉）

### 4. 修改前必须理解调用关系

动手前必须能说出（并写进回复）：

```
要改：<文件>:<行号> —— <符号名>
谁调用它：<N> 个文件（列出 3 个典型）
它调用谁：<列出>
受影响的任务：<列出>
级别：A / B / C / D
```

N 必须是 grep 出来的**实数**，不是估计。

### 5. 无法测试时必须明确说明

OAS 是"看屏幕点屏幕"的程序，**正确性只能靠实机运行验证**。当前环境无运行配置、无 `log/`、无模拟器 → **AI 无法验证任何运行期行为**。

不许说"应该没问题""逻辑上是对的"。要写：改了什么 / 怎么验 / **什么没验**。

## 七条红线（做了就是犯错）

1. **给识别/OCR 的 RPC 加 try/except 兜底** —— 会掩盖"服务根本没起来"
2. **给 `Device` 类新增属性** —— 会照抄 `device.py:29-33` 的类属性写法埋雷
3. **在 `GeneralBattle` / `SwitchSoul` 里加任务特判** —— 一次影响 33 / 32 个任务
4. **批量重命名符号** —— 任务名三处硬编码，漏一处就"配了从来不跑"
5. **把 `raise TaskEnd` 改成 `return`** —— 任务会被判失败，3 次后退出程序
6. **动 `module/atom/scatter.py`** —— 半移植文件，动它必炸
7. **合并 AzurTian 的任何代码** —— 它是下游，合并 = 回退三个月

## 改前必做

- [ ] 定位到**具体文件和行号**（不许说"大概在 config 里"）
- [ ] `grep -rl "<符号名>" --include=*.py .` 算出引用面
- [ ] 确认要改的是**实例属性还是模块级全局**（`assets.py` 里全是全局单例）
- [ ] 确认有没有 `# This file was automatically generated` 标记
- [ ] 判断是否需要同步改 `config_model.py` / `config_menu.py`
- [ ] 判断改动是否跨**进程边界**（脚本 ↔ 图像服务 22269 ↔ OCR 服务 22268）

## 改后必做

- [ ] 说明改了哪几个文件的哪几行
- [ ] 列出受影响的其它任务
- [ ] 给出**具体**的验证方法
- [ ] 写明**未实机验证**的部分
- [ ] 若动过识别规则 → 提醒"需要重新截素材并跑生成器"

## 回复格式（四段，缺一不可）

```
【改了什么】
  文件:行号 —— 改动内容

【影响范围】
  受影响的任务/文件：...
  级别：A/B/C/D

【如何验证】
  1. ...
  2. ...

【未验证项】   ← 确实没有就写"无"，但这段不能省
  ...
```

## 定级速查

```
🔴 A（禁止自主改）
   module/atom/*、module/device/*、script.py、tasks/base_task.py、
   module/exception.py、module/config/config.py、config_model.py、atom/scatter.py

🟠 B（改前列调用关系）
   Component/{GeneralBattle,SwitchSoul,GeneralInvite,GeneralRoom,Buy}/*、
   tasks/GameUi/*、module/logger.py、config/{anti_ban,scheduler,config_menu}.py、
   module/{image,ocr}/rpc.py

🟡 C（可改，守三条硬约束）
   tasks/<玩法>/script_task.py、config.py

🟢 D（最安全）
   GotoMain、ActivityShikigami、DyeTrifles、GoryouRealm、Costume、FrogBoss

⛔ 禁编辑
   tasks/*/assets.py、fluentui/、bin/
```

A/B 级不是"不能改"，是"**不能自主改**"。确实要动时：把要改的那几行和理由单独列出来，等人确认。
